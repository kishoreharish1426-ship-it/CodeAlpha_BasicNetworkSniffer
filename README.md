# CodeAlpha Basic Network Sniffer

## Description
A Python-based network packet sniffer developed as part of the CodeAlpha Cyber Security Internship.

## Features
- Captures live network packets
- Displays source and destination IP addresses
- Detects TCP, UDP, and ICMP protocols
- Shows packet capture timestamps
- Saves packet details to a log file

## Technologies Used
- Python
- Scapy
- Npcap

## How to Run

1. Install Python
2. Install Scapy:
   pip install scapy
3. Install Npcap (Windows)
4. Run:
   python network_sniffer.py
